À propos du projet

Ce projet de stage a été réalisé dans le cadre de la digitalisation des processus médicaux. L'objectif était de développer une plateforme web permettant aux médecins de créer, gérer et suivre les ordonnances médicales de leurs patients de manière numérique et sécurisée.

Fonctionnalités principales

  • Création et gestion d'ordonnances médicales avec interface intuitive
  • Génération automatique de PDF professionnels pour les ordonnances
  • Base de données de médicaments avec recherche et filtrage
  • Gestion des patients et historique des ordonnances
  • API RESTful pour l'intégration avec d'autres systèmes
  • Interface responsive accessible sur tous les appareils

Stack technique

Front-end : React.js avec une architecture component-based, hooks personnalisés pour la logique métier, et un design system responsive.
Back-end : PHP/Laravel avec Eloquent ORM, API RESTful, middleware d'authentification, et système de validation des données.
Base de données : MySQL avec schéma relationnel optimisé.
PDF : Intégration d'une bibliothèque de génération PDF pour produire des ordonnances conformes aux standards médicaux.

Défis techniques

La génération de PDF formatés conformément aux normes médicales a été le principal défi technique. Il a fallu concevoir un template flexible capable de s'adapter à différents types d'ordonnances tout en restant lisible et professionnel. L'intégration entre le front-end React et l'API Laravel a nécessité une attention particulière sur la gestion des erreurs et le loading states.
