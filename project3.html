À propos du projet

Ce projet a été développé lors du hackathon organisé par Capgemini Maroc. L'objectif était de concevoir une solution innovante d'automatisation du traitement documentaire en utilisant un système multi-agents capable de raisonner et de prendre des décisions de manière autonome.

Architecture du système

Le système est composé de quatre agents spécialisés fonctionnant en pipeline :

  • Agent Intake : Réception et prétraitement des documents source
  • Agent Classification : Classification automatique du type de document
  • Agent Extraction : Extraction des informations clés via OCR et NLP
  • Agent Validation : Vérification et validation des données extraites

Technologies utilisées

Back-end : Python/Django pour l'orchestration des agents et l'API.
OCR : Intégration de moteurs de reconnaissance optique de caractères pour l'extraction de texte à partir de documents scannés.
Prompt Engineering : Utilisation du framework CoStar pour structurer les prompts adressés aux modèles de langage.
Multi-agents : Architecture agentique avec communication inter-agents et prise de décision distribuée.

Résultat

Notre équipe FiveLinks a été classée parmi les 5 finalistes sur 85 équipes participantes. Cette expérience m'a permis de découvrir le domaine passionnant des systèmes multi-agents et de l'ingénierie de prompts, des compétences de plus en plus recherchées dans le domaine de l'IA.
